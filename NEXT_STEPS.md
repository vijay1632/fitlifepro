# ⚡ VERCEL DEPLOYMENT - 5 STEPS ONLY

Choose ONE step to proceed:

## Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit"
# Create repo at https://github.com/new
git remote add origin https://github.com/YOUR_USERNAME/fitlifepro.git
git push -u origin main
```

## Step 2: Deploy on Vercel
- Visit: https://vercel.com
- Sign up with GitHub
- Click "Add New Project"
- Select "fitlifepro"
- Click "Deploy"

## Step 3: Create Free Database
- Visit: https://supabase.com
- Create new project: "fitlifepro"
- Copy connection string

## Step 4: Add Environment Variables
In Vercel Project Settings:
- DATABASE_URL = (Supabase connection string)
- AUTH_SECRET = (random 32+ char string)

## Step 5: Your App is Live!
URL: https://fitlifepro.vercel.app
